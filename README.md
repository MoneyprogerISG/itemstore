# itemstore

HTTP-сервис на Go с CRUD API для хранилища товаров. Учебный проект, в котором собраны слоистая архитектура, интерфейсы, дженерики, обработка ошибок, конкурентный доступ и тесты. Внешних зависимостей нет, только стандартная библиотека.

## Возможности

- REST API: создание, чтение, обновление и удаление товаров (`/items`)
- Слоистая архитектура: **handler → service → repository**, слои связаны через интерфейсы
- Обобщённый (generic) in-memory репозиторий `InMemoryItemRepo[V Identifiable]`, потокобезопасный за счёт `sync.RWMutex`
- Генерация ID через `atomic.Int64`, без гонок при параллельных запросах
- Доменные ошибки (`ErrNotFound`, `ErrAlreadyExists`, `ValidationError`) переводятся в HTTP-коды через `errors.Is` / `errors.As`
- Роутинг на `net/http.ServeMux` с шаблонами Go 1.22+ (`GET /items/{id}`)
- Структурированные логи в JSON (`log/slog`)
- Конфигурация через переменную окружения `PORT`

## Структура

```
itemstore/

    ├── service/                # бизнес-логика и валидация
    ├── service_test/           # unit-тесты сервиса
    └── handler/                # HTTP-обработчики
```

## API

| Метод  | Путь          | Описание               | Успех | Ошибки        |
|--------|---------------|------------------------|-------|---------------|
| GET    | `/items`      | Список всех товаров    | 200   | —             |
| GET    | `/items/{id}` | Товар по ID            | 200   | 404           |
| POST   | `/items`      | Создать товар          | 201   | 400           |
| PUT    | `/items/{id}` | Обновить товар         | 200   | 400, 404      |
| DELETE | `/items/{id}` | Удалить товар          | 204   | 404           |

Модель:

```json
{ "id": "1", "title": "Книга", "description": "Go in Action", "price": 1200 }
```

Валидация: `title` обязателен, `price` не может быть отрицательным.

## Запуск

Нужен Go 1.22 или новее.

```bash
go run ./cmd/server             # сервер на :8080
PORT=9000 go run ./cmd/server   # другой порт
```

Примеры запросов:

```bash
curl -X POST localhost:8080/items -d '{"title":"Книга","description":"Go in Action","price":1200}'
curl localhost:8080/items
curl localhost:8080/items/1
curl -X PUT localhost:8080/items/1 -d '{"title":"Книга","price":990}'
curl -X DELETE localhost:8080/items/1
```

## Тесты

```bash
go test ./...
go test -race ./...   # проверка на гонки данных
```

Что покрыто тестами:
- табличные тесты создания и обновления с валидацией;
- обработка `not found` для получения и удаления;
- конкурентное создание записей (уникальность ID при параллельных вызовах);
- конкурентный доступ к репозиторию.
